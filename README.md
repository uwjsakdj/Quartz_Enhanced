Quartz_Enhanced
A Forge mod that expands gameplay and practical uses for quartz in Minecraft.
Official Download Channels
This mod is officially published on the following platforms. Any download links not listed here are untrusted, please exercise caution:
CurseForge: https://www.curseforge.com/minecraft/mc-mods/quartz-enhanced
Modrinth: https://modrinth.com/mod/quartz_enhanced/versions
Repository Status
This mod is not fully open-source at this time. This repository only hosts a small set of necessary public files.
Any future changes to the open-source status will be announced in this repository.
Issues & Suggestions
You may submit bug reports or feature requests on the Issues page of this repository.
Please follow these guidelines when submitting:
Clearly mark the issue type in the title — for example:
[Bug] Recipe missing
[Suggestion] Recipe optimization
Always include the mod version, Minecraft version, and mod loader version in bug reports
If you encounter a game crash, please attach the full crash report to help us locate the problem quickly.
